# How to install

Qalam runs on:

| Computer | Needs | Download |
|---|---|---|
| **Mac** (Apple Silicon M1 or later, or Intel) | macOS 13 Ventura or later | `Qalam-mac.pkg` (one file for both kinds of Mac) |
| **Windows PC**, 64-bit Intel or AMD | Windows 10 or 11 | `Qalam-Setup-x64.exe` |
| **Windows PC**, ARM (Snapdragon, Surface Pro X) | Windows 11 on ARM | `Qalam-Setup-arm64.exe` |

The **Download** button on the [website](https://sashakib.github.io/qalam/) picks the right file for your computer. Every file is also on the [releases page](https://github.com/SaShakib/qalam/releases/latest).

> **Not sure which Windows you have?** Open **Settings → System → About** and look at **System type**. "x64-based processor" means `x64`. "ARM-based processor" means `arm64`.

Then follow the steps for your computer:

- **[Install on Mac](install-mac.md)**
- **[Install on Windows](install-windows.md)**

After installing, Qalam opens a short **[guided setup](getting-started.md)**.

## Why does my computer warn me?

Qalam is free and open source, and the source is all [on GitHub](https://github.com/SaShakib/qalam). Macs and Windows PCs warn about apps that aren't signed with a paid developer certificate. Until Qalam's downloads are signed, you may see **one** warning when you first install. The install pages show exactly what to click. Updates after that install by themselves without the warning.

On a phone, tablet or Linux, you can't install the keyboard, but you can use the typing pad on the [website](https://sashakib.github.io/qalam/#demo) and copy the Arabic.
