# Qalam documentation

Qalam (قَلَم) is a free phonetic Arabic keyboard for **Mac** and **Windows**. You type Arabic the way you spell it: each letter, then its haraka. Sukūn and shadda appear by themselves, and the hamza seat, the article and tanwīn are handled for you.

```
kitaAbuN → كِتَابٌ     saAala → سَأَلَ     eilmuN → عِلْمٌ     alshamsu → الشَّمْسُ
```

## New here?

1. **[Install Qalam](install.md)** on your Mac or Windows PC.
2. **[Follow the first-time setup](getting-started.md).** Qalam opens a short guided setup by itself after you install it.
3. **[Learn the basics of typing](typing.md)**, then keep the **[key chart](../LAYOUT.md)** nearby.
