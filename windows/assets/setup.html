Welcome to Qalam

Type Arabic the way you spell it: each letter, then its haraka. Sukūn and shadda appear by themselves. These steps take about two minutes, and you can change everything later from the ق icon in the system tray.

Qalam is already running. Try it here: type kataba then Space.

Switch between Arabic and English

Qalam works in every app. Turn it on when you want Arabic, off for English.

Shortcut
Press it anywhere to switch.
Or click the tray icon
Bottom right of the taskbar (under ^ if hidden). Green ق = Arabic on. Right-click it for every setting.
Arabic typing is
While you type a word, a small box shows the Arabic. Space or punctuation puts it in, Backspace removes the last English key, Esc gives back the English letters.

Writing style

Everyday is standard modern spelling. Qur'an style adds ٱ, dagger alif, maddah and the mushaf spelling.

Madinah-mushaf sukūn in Qur'an style
قۡ instead of قْ (needs a mushaf font such as KFGQPC Hafs).

Shortcuts

Change any that clash with shortcuts you already use. Click Change, then press the new keys anywhere (hold Ctrl or the left Alt). The buttons in the typing box always work too.

Press the new shortcut now… Esc cancels, Backspace means no shortcut.

Fonts

Qalam types Unicode Arabic, so the app you type in chooses the font. Pick an Arabic font there (in Word: the font box, then Complex scripts).
